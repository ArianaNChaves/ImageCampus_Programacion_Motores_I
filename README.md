## English

This is a solo-developed university project based on a two-player Pong-style game.

### Controls

- **W / S** – Move Player 1
- **Up / Down Arrow** – Move Player 2
- **P** – Pause the game


---

## Español

Este es un proyecto universitario desarrollado en solitario basado en un juego de Pong para dos jugadores.

### Controles

- **W / S** – Mover al Jugador 1  
- **Flecha Arriba / Flecha Abajo** – Mover al Jugador 2  
- **P** – Pausar el juego
